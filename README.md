# AprilPlus

AprilPlus 是一个基于 Fabric 的 Minecraft 模组，面向 26w14a 快照版本，包含愚人节风格内容增强与一些客户端辅助功能。

## 主要功能

- 灵魂出窍（Free Camera）
- 伽马覆写（Gamma Toggle）
- 活化方块分组快速切换（小键盘 `0~6` 与 `.`）
- 双击快速选中附近相同活化方块
- `Shift + 右键` 取消选中、`Shift + 双击右键` 取消全部选中
- 熔炉不会熔炼被选中的物品

> 以上功能基于 `CHANGE_LOG.md` 与客户端按键代码整理，详细变更请查看 `CHANGE_LOG.md`。

## 默认按键

- `G`：伽马覆写（`Gamma Toggle`）
- `` ` ``（反引号）：灵魂出窍（`Free Camera`）
- 小键盘 `0`：Group None
- 小键盘 `1`：Group Red
- 小键盘 `2`：Group Blue
- 小键盘 `3`：Group Lime
- 小键盘 `4`：Group Yellow
- 小键盘 `5`：Group Purple
- 小键盘 `6`：Group Aqua
- 小键盘 `.`：Group All
